# Bug Fixer

此技能专注于分析和修复代码中的 Bug。

## 能力
- 分析报错信息和堆栈跟踪
- 定位代码中的逻辑错误
- 提供修复方案并应用代码更改
- 验证修复结果

## 使用场景
- 用户提供报错日志
- 用户指出具体功能的异常行为
- 代码审查中发现的潜在问题

## 使用步骤
1. **收集信息**：询问用户关于错误的详细信息，如重现步骤、错误日志等。
2. **定位问题**：使用 `grep` 或 `search` 工具定位相关代码。
3. **制定方案**：分析原因并提出修复方案。
4. **实施修复**：使用 `SearchReplace` 或 `Write` 工具修改代码。
5. **验证修复**：运行测试或让用户验证。
